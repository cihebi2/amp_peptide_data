Methods

证据状态边界

  • source_verified：当前 primary literature evidence 支持该数据库记录。
  • source_conflict：数据库字段与论文证据存在冲突、粒度压缩或单位/对象差异。
  • database_only_no_primary_source：数据库断言当前 primary source 无可定位支持。
  • unresolved_record：材料或行级映射不足，不能安全判定。
