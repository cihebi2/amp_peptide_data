# AMP Evidence Atlas v1.0 来源版本与许可审查

时间戳：2026-07-28 17:48 CST  
数据版本：`amp-evidence-atlas-v1.0`  
结论：**版本审查已完成；五库原始数据的公共再分发许可尚未全部闭环。**

> 本文是工程与发布风险审查，不是法律意见。“网站能访问”或“论文是开放获取”
> 不自动等于“数据库原始字段可被整库镜像并再次授权”。

## 1. 大白话结论

1. 五个来源库的本地快照、抓取日期、记录数、主文件和 SHA-256 已固定在
   `SOURCE_DATABASE_VERSIONS.tsv`。
2. **DRAMP** 明确采用 CC BY 4.0，普通/临床数据可在署名条件下使用；
   但专利 AMP 明确要求另行授权。
3. **APD6、CAMP、dbAMP** 允许访问或学术使用，但目前找到的官方条款
   没有明确授予“把原始导出整库公开再分发”的权利。
4. **DBAASP** 的同一份条款一处说可自由复制/分发，下一处又禁止向任何人
   分发，必须取得书面澄清。
5. 因此 v1.0 可以作为**内部可复现的数据冻结**和论文分析基础，但目前不能把
   包含五库复制字段的完整 TSV 直接声明为“已获许可、可无限制公开下载”。

## 3. 逐库许可判断

### APD6

官方[下载页](https://aps.unmc.edu/downloads)允许研究和教育使用并要求引用
APD3/APD6，同时标注 UNMC `All Rights Reserved`。这足以支持当前学术研究使用，
但不是明确的整库公开再分发许可。

**决定：** 未获得书面许可前，不公开镜像 APD6 原始导出；公共 Atlas 仅保留
经过字段级权利审查的项目自建注释、来源标识和必要短引文。

### CAMP

[CAMP_R4 论文](https://academic.oup.com/nar/article/51/D1/D377/6825344)
说明资源开放访问，但本次没有找到单独、明确的数据库数据再分发许可证。
开放访问只说明能访问，不自动授予整库复制和再次许可。专利集合风险更高。

**决定：** CAMP 原始字段和专利集合暂不进入公共批量下载，先取得书面条款。

### DBAASP

官方[使用条款](https://www.dbaasp.org/docs/DBAASP_Terms_And_Conditions.pdf)
内部冲突：先称数据为 public domain、可自由复制和分发，随后又要求访问者不得
以任何形式向任何人分发数据。

**决定：** 采用最保守解释；在 DBAASP 书面澄清前，不公开整库镜像，不把
DBAASP 复制字段纳入可再授权下载包。

### DRAMP

官方[首页](https://dramp.cpu-bioinfor.org/)明确采用 CC BY 4.0，并允许访问、
使用、下载和提取数据；同时要求普通/临床 AMP 引用原作者，专利 AMP 另行授权。

**决定：** 普通/临床数据在完整署名与 CC BY 4.0 标识下可进入公共导出；
专利来源记录必须过滤，除非保存了具体授权。

### dbAMP

官方[下载页](https://ycclab.cuhk.edu.cn/dbAMP/download.php)提供 LICENSE。
本地保存的官方 LICENSE（SHA-256
`b2f9535a7d53a2ed20223fc7d91f253010c01e11bb1885e413617b3290a35cea`）
只明确“免费学术使用”，没有明确授予公共再分发或商业使用权。

**决定：** 学术内部使用继续保留；公共原始字段下载需要书面许可。

## 4. 对网站/API/下载的强制规则

公共服务上线前必须同时满足：

1. 导出器按来源和字段执行 rights filter，不直接复制未获许可的整库字段；
2. DRAMP 专利记录默认排除；
3. 每条公开数据保留来源、版本、署名和许可状态；
4. 项目原创的证据等级、冲突类型、原文定位与来源库复制字段分层存储；
5. 在来源权利未闭环前，不给完整混合数据包统一套用 CC BY/MIT 等许可证；
6. 新取得的书面许可作为追加治理文件保存，不修改 v1.0 不可变科学负载。

该服务公开：

- 9,263个项目派生的肽聚合摘要；
- 活性、审计、机制和冲突的聚合统计；
- 40题项目自建 grounding benchmark；
- 只读、CORS-enabled API 与 OpenAPI 3.1 文档。

该服务不公开：

- 五库原始记录镜像；
- `source_id`、数据库记录名、数据库值/单位等复制字段；
- 逐行数据库—原文对照；
- 论文全文、PDF、表格或图片；
- DRAMP 专利 AMP 内容。

这意味着“公共网站/API 已部署”，但不意味着完整内部 v1.0 包已经获得公共
再分发授权。完整包继续保持 `public_release_ready=false`。
